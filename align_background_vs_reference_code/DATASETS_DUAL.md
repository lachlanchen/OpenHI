# Dual Three‑Panel Overlays (Blank + Sample + GT)

This note records the dual‑overlay figure that combines:
- **Blank** (light‑source only)
- **Sample** (dicot stem; previously mislabeled “sanqin”)
- **Ground‑truth spectrometer SPD**

The figure is generated by a dedicated script:
- `align_background_vs_reference_code/compare_publication_three_panel_dual.py`

## Command Used (current best)

This run applies a **simple wavelength shift** to the sample curve to align it to GT.
We found that shifting the sample **50 nm left** makes the left edge match GT.

```bash
python align_background_vs_reference_code/compare_publication_three_panel_dual.py \
  --segment-blank scan_angle_20_lumileds/angle_20_blank_20250922_170433/angle_20_blank_event_20250922_170433_segments/Scan_1_Forward_events.npz \
  --segment-sample scan_angle_20_lumileds/angle_20_sanqin_20250922_170630/angle_20_sanqin_event_20250922_170630_segments/Scan_1_Forward_events.npz \
  --gt_files reference_spectrum_lumileds/USB2F042671_16-04-56-391.txt \
  --step_ms 2.0 --bin_ms 5.0 \
  --sensor_width 1280 --sensor_height 720 \
  --label-blank "Blank" --label-sample "Dicot stem" \
  --sample-shift-nm -50 \
  --suffix lumileds_blank_dicot_shift50 \
  --output_root align_background_vs_reference_code
```

## Alignment Logic (what changed and why)

Originally, the sample was aligned using **plateau‑based affine scaling**, which could push the curve below 0 and
produce unstable results. This is not robust when sample intensity has real absorption and does not share the
same plateau values as the blank/GT.

The alignment logic was simplified to a **pure wavelength shift** for the sample:

- New argument: `--sample-shift-nm` (manual shift in nm).
- Optional convenience: `--auto-shift-sample-left-edge` (align sample left edge to GT left edge).

This is **more stable** and keeps the sample curve shape intact while aligning the left edge (the main mismatch in
this dataset). No amplitude scaling is applied anymore.

## Notes

- The script uses **blank** to define the wavelength–time mapping (λ(t)).
- The sample shares the same mapping but can be shifted with `--sample-shift-nm`.
- If you want to try automatic left‑edge alignment, replace `--sample-shift-nm -50` with
  `--auto-shift-sample-left-edge`.
